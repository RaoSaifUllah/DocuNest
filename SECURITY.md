# Security reporting

Do not put credentials, documents, OCR text, or exploit payloads in public issues. Contact the repository owner privately using a channel they publish when the repository is released. No reporting address is configured yet.

The implementation targets applicable OWASP ASVS 5.0 Level 2 controls and WCAG 2.2 AA; it is not certified. Server OCR and search see plaintext. Encrypted volumes, temporary storage, swap and backups are deployment requirements. Share download controls cannot prevent screenshots.
